# Asset provenance

The campus courtyard illustration at `client/src/assets/campus.svg` is original SVG artwork authored for this redesign with AI assistance: students planning a shared activity, campus buildings, trees and a noticeboard. The stacked-paper brand mark and empty-detail icon are original inline SVG geometry. No reference image, stock image, external font, hotlinked asset or generated raster image is used.

These new illustration and icon assets may be used, modified and redistributed with the project without additional attribution or fees. There are no third-party asset license obligations. Typography uses locally available Georgia and Segoe UI with serif/system fallbacks; those fonts are not bundled or downloaded. CSS supplies the motion and surface treatments; no animation or icon package is added.

The illustration is decorative (`alt=""`), and inline icons use `aria-hidden="true"`. All functional text remains available independently of the artwork. The entire animation/transition layer is disabled by `prefers-reduced-motion: reduce`.
